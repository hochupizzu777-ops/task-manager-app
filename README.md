# Task Manager App

Консольное приложение для управления задачами, пользователями
и проектами на Java.

## Возможности

- Создание, поиск, изменение и удаление задач.
- Статусы, приоритеты и сроки выполнения.
- Поиск по названию, фильтрация и сортировка.
- Просмотр просроченных задач.
- Управление пользователями и назначение исполнителей.
- Управление проектами и их участниками.
- Перенос задач между проектами.
- Сохранение и восстановление данных.

## Требования

- JDK 21.
- Apache Maven.

## Сборка и проверка

Выполнить из корня проекта:

```shell
mvn clean verify
```

## Запуск

После успешной сборки выполнить из корня проекта:

```shell
java -cp target/task-manager-app-1.0.0.jar ru.learning.taskmanager.Main
```

Также приложение можно запустить через метод main класса
ru.learning.taskmanager.Main в IntelliJ IDEA.

## Хранение данных

Данные записываются в файл data/tasks.properties
при выходе через пункт 0 главного меню.

Пункт 0 вложенного меню возвращает в главное меню.

При следующем запуске задачи, пользователи, проекты
и связи между ними восстанавливаются автоматически.

Путь к файлу отсчитывается от рабочей папки приложения.

## Основные правила

- Исполнитель задачи проекта должен быть его участником.
- Участника нельзя исключить, пока у него есть назначения
  в этом проекте.
- Пользователя нельзя удалить, пока он состоит в проектах
  или имеет назначенные задачи.
- Проект нельзя удалить, пока в нём есть задачи.
- Задача считается просроченной, если срок раньше текущей
  даты и задача ещё не завершена.

## Структура

- model — модели данных.
- repository — интерфейсы и реализации хранилищ.
- service — операции и правила приложения.
- console — консольный интерфейс.
- storage — чтение и запись файла.
- exception — исключения приложения.

## Тестирование

JUnit-тесты проверяют сроки задач, файловое хранение
и правила взаимодействия пользователей, проектов и задач.
